# Monsterknacker

Einmaleins-Lernapp für Kinder – Vue 3 + TypeScript, läuft als einzelne HTML-Datei.

Quick & Dirty mit Claude Code entwickelt.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
# Erzeugt dist/index.html (alles in einer Datei, kein separates JS/CSS)
```
